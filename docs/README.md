# Docs

Everything non-code lives here, organized by what question it answers.

| Folder | Answers | Owner |
|---|---|---|
| `product/` | What are we building and why? | Product/founder |
| `architecture/` | How do the pieces fit together? | Backend/tech lead |
| `database/` | What does the data look like? | Backend |
| `api/` | What can the frontend call? | Backend |
| `roadmap/` | What do we build next, in what order? | Whole team |
| `decisions/` | Why did we choose X over Y? | Whoever made the call |

**Start here if you're new**: `product/master-blueprint.md` → `roadmap/build-plan.md` → `architecture/`.
