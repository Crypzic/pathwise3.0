# Product docs

**Purpose**: the "what and why" — vision, features, monetization, gamification design, non-code founder/ops fundamentals.

**Ownership**: product/founder. Changes here should be discussed before merging — this is the source of truth other docs (roadmap, architecture) are supposed to match.

**Contents**:
- `master-blueprint.md` — full product spec: vision, principles, features, monetization, gamification, international approach.
- `ops-checklist.md` — non-code fundamentals: legal, privacy compliance, AI cost economics, team process.

**Convention**: if a product decision changes, update this doc *and* add an entry to `docs/decisions/` explaining what changed and why — don't just silently edit history.
