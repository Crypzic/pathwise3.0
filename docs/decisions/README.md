# Decisions (ADRs)

**Purpose**: a running log of non-trivial decisions and the reasoning behind them, so nobody re-litigates a settled argument three months from now — or worse, reverses a decision without realizing why it was made.

**Ownership**: whoever made or drove the call, but anyone can propose one.

**Convention**: one file per decision, numbered sequentially: `0001-title.md`, `0002-title.md`. Keep each one short:
- **Context** — what prompted this decision
- **Decision** — what was decided
- **Consequences** — what this rules in/out going forward

Add a new one whenever you: pick a stack/library over an alternative, drop or defer a feature, change monetization/pricing logic, or reverse an earlier decision.
